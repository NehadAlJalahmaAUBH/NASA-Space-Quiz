# Space Explorer Quiz 🚀

## Project Idea
A simple educational web app that teaches students about the planets in our
solar system and tests their knowledge with a quiz. It supports NASA's STEM
outreach goals by making space science fun and accessible for young learners.

## Technologies Used
- HTML, CSS, JavaScript
- GitHub (issues, labels, project board, branches, pull requests)

## How to Run
1. Clone the repo: `git clone https://github.com/NehadAlJalahmaAUBH/space-explorer-quiz.git`
2. Open the project folder.
3. Open `index.html` in any web browser. No installation needed.

## How to Use
- Scroll through the planet cards to learn facts about each planet.
- Click "Start Quiz" to answer questions and see your score.
